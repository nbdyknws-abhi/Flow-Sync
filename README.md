# FlowSync

FlowSync is a high-velocity, modern workspace and project coordination application. It empowers teams by eliminating redundant status meetings, automating tool sync pipelines (like Slack and Linear), and providing unparalleled insights into team velocity.

## 🚀 Key Features

- **Interactive Kanban Board**: Fully draggable and interactive task tracking.
- **Velocity Analytics**: Real-time interactive charts providing data on sprint resolution rates and team capacity.
- **Smart Automations**: Visual workflow builders demonstrating integration hooks with Stripe, Github, Slack, and Linear.
- **Premium Design**: Modern aesthetic utilizing deep slate and indigo color palettes, micro-interactions, responsive flex-grids, and CSS mesh gradients.
- **Enterprise-Grade Focus**: High-conversion landing page outlining compliance, single sign-on (SSO), and top-tier security standards.

## 💻 Tech Stack

- **Framework**: [React](https://reactjs.org/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🛠 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:
   ```sh
   git clone <your-repo-url>
   ```
2. Navigate into the directory:
   ```sh
   cd AntiGravity
   ```
3. Install NPM packages:
   ```sh
   npm install
   ```

### Running the App Locally

Start the Vite development server:
```sh
npm run dev
```

Open your browser and navigate to `http://localhost:5173` (or the port specified in your console).

### Building for Production

To create a production build:
```sh
npm run build
```
This command compiles the React code and Tailwind CSS into an optimized `dist` folder.

## 📱 Responsive Layout
FlowSync is engineered to scale beautifully on any device, from massive desktop monitors down to the narrowest mobile screens, dynamically collapsing grids and leveraging responsive font-scaling rules.
